# Mama Evi Landing Page

Static, responsive TR/EN landing page for Mama Evi.

## Files
- `index.html` — page structure and text
- `styles.css` — responsive design
- `script.js` — TR/EN switch, mobile menu and reveal effects
- `assets/` — Mama Evi logo, app screenshots and promotional visual

## Local preview
Double-click `index.html` to open it in a browser. For the most reliable preview, use VS Code + Live Server if available.

## GitHub Pages
1. Create a new public GitHub repository, e.g. `mamaevi`.
2. Upload everything in this folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Branch: `main`; folder: `/ (root)`; click **Save**.
6. GitHub will show the public URL after deployment.
